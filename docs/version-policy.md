# 版本与目录规则

根据用户在 2026-09-28 的要求：

- 当前版本归档为 `V0.1`。
- 未指定新版本号时，后续改进依次使用 `V0.2`、`V0.3` 等；递增的是小数点后的版本序号（如 `V0.9` 后为 `V0.10`）。
- 小数点前的主版本号仅在用户明确确认后增加。
- 每个新版本必须使用新的独立工作目录，再进行试验、修改与验证。
- 已归档版本的源码、安装包、版本标签和发行资料保留，不在原版本中改动。修复也进入后续版本。
- 本机归档位于 `versions/<版本号>/`，不重复提交整个源码副本到 Git；GitHub 上由对应版本标签及发行附件保留版本内容。
- 每版记录功能改进、验证结果和仍待完成的事项，发布内容以实际完成状态为准。

`V0.1` 归档后，尚未收到具体改进建议，因此不提前创建或修改 `V0.2`。
