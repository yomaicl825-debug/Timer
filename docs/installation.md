# 安装说明

## Windows

从 GitHub Releases 下载 `Timer-*-windows-setup.exe`，运行后从开始菜单打开 Timer。也可下载 `Timer-*-windows-portable.zip`，完整解压后运行 `study_timer.exe`。安装包目前没有商业代码签名，Windows 可能显示发布者未知。请核对同一发行页的 SHA-256 值。

## Android

从 GitHub Releases 下载 `Timer-*-android.apk`，在系统文件管理器打开并按提示允许本次来源安装。只从本项目的 GitHub Releases 下载，并核对 SHA-256。发布 APK 使用项目专属的持久签名密钥；调试 APK 不作为公开发行包。

## 数据

未登录时数据仅保存在当前设备。登录后不同账号的数据相互隔离；本机未登录记录不会自动合并到账号。删除应用前请先确认数据已同步。V1 尚无导出与恢复入口。

## iPhone

iPhone 版尚未发布。GitHub 上的源码不能直接在 iPhone 上安装，后续需完成 iOS 构建、签名和分发。
