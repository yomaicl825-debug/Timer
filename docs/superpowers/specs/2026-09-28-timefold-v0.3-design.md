# Timefold V0.3 设计说明

日期：2026-09-28

基准：已发布的 V0.2（7d3998d）

状态：设计已整理，等待用户核对；尚未修改应用代码。

## 本版要做到什么

面向本人、同学和家人使用的学习计时应用，本版改善语言与外观。保留已有任务、计时、统计、账号与历史记录使用方式。

### 1. 名称和图标

- 软件显示名称确定为 **Timefold**，中英文模式都使用这个名字。
- 图标采用第一轮概念图左上角的原始 **A1**，不采用后来的粗细、切口或折角变化版。
- 左侧是黑色倒 L（┐），右侧为独立黑色三角折角；保留原始比例与间隙。
- 按该轮廓制作清晰的矢量源文件，再导出 Windows ICO、Android 各尺寸图标。
- 按用户最新选择，图标采用 **透明背景**，只保留原始 A1 黑色图形，不添加白色底板、方形底色或装饰边框。源 SVG、PNG 与 Windows ICO 保留透明通道；Android 平台资源采用相同透明图形，并在构建验证时核对实际显示效果。
- 原始概念图作为比对依据：`D:/Timer/previews/V0.3-design/T-icon-concepts-01.png`；单独放大预览：`D:/Timer/previews/V0.3-design/A1-original-closeup.png`。
- Windows 应用窗口、安装器和 Android 应用显示名称统一；包标识、原有数据库位置与登录数据身份保持稳定，确保升级可继续使用已有记录。

### 2. 中英文切换

- 入口：**个人主页 → 设置 → 语言 / Language**。
- 提供 **中文**、**English** 两个选项，点击立即生效，重启后保持选择。
- 首次使用时根据系统语言选中文或英文，非中文系统选英文；已有安装首次升级按同样规则初始化，用户可随时手动选择。
- 覆盖任务主页、个人主页四个分区、账号、弹窗、按钮、计时状态、应用内提示、可理解的错误提示和辅助说明。
- 用户输入的任务名、历史备注等内容保留原文，不自动翻译。
- 全屏时钟继续使用 `YYYY / MM / DD` 与英文星期缩写，保持既有简洁排版。
- 统计页面、普通日期与时长说明使用所选语言；时区标识与数字时长不因切换语言而改变含义。
- Windows 主窗口与已打开的全屏/紧凑计时窗口一起更新界面语言。切换语言不重新开始计时，也不改变计时阶段或已累计时长。

### 3. 灰色主题

- 背景采用用户选定的 **G：`#141414`**。
- 主文字采用更暗一档的浅灰 **`#C4C4C4`**，辅助文字为 **`#A8A8A8`**。
- 左侧导航、分隔线和选中项使用相邻灰度，维持现有布局层次。
- 灰色主题中普通文本、图标、按钮和全屏时间统一使用对应浅灰前景，避免部分内容仍为纯白。
- 白底黑字、黑底白字两个已有主题仍可选择。
- 字号与字体切换沿用 V0.2；本版不再次改变页面排版。
- 配色参考：`D:/Timer/previews/V0.3-design/deeper-grays/gray-G-dimmed.png`。

## 实现边界

- 增加集中管理的中文、英文翻译资源，使用 Flutter 的本地化机制处理界面与系统控件文案。
- 设置沿用现有持久化方式；新增语言偏好，不移动或清空数据库。
- 将界面中写死的文案逐页替换。业务层异常在显示时转换为对应语言的提示，避免已经生成的中文状态字符串在切换后继续出现。
- 扩展已有 Windows 窗口外观通知，让语言随主题、字体一起更新。子窗口只更新展示偏好，不重置计时数据。
- 应用显示名称与资源图标更新；维持原有更新路径和记录兼容性。
- 未配置 CloudBase 环境时继续提供本地功能；本版不新增云托管、公共 Android 签名或 iOS 上架流程。

## 如何检查

1. 中文、英文逐页检查，尤其是英文按钮较长时的布局与手机导航。
2. 切换语言后立即更新，重启后保持选择；任务名与已有记录保持原样。
3. 运行中的计时器切换语言、主题、字体后，计时、暂停状态与累计时长不被重置。
4. Windows 全屏窗口及紧凑窗口检查语言同步；实际原生窗口未能验证时在交付说明中明确记录。
5. 三种主题都检查，灰色主题的全屏时间和普通文字不使用纯白。
6. A1 图标与原图比对，检查透明通道、常见小尺寸、Windows 图标资源与 Android 图标资源；不人为添加底色。
7. 跑现有回归测试、静态检查和可用的 Windows/Android 构建验证；发布时报告实际通过的检查与未完成项。
