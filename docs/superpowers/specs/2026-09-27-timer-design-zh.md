# Timer 第一版：给使用者看的设计说明

日期：2026 年 9 月 27 日  
软件暂用名：Timer。正式发布前可以改名。

## 这款软件要做什么

它帮助你、家人和同学记录学习时间。你可以按任务查看从开始使用至今累计学了多久，也可以在个人主页看每天、每周、每月的学习时长。它不会要求你设定全年目标或截止日期。每个人只能看到自己的记录。

第一版先做 Windows 软件和 Android App，供大家从 GitHub 下载试用。以后再做面向 iPhone 的正式公开版。第一版没有网页端。项目源代码公开，采用 MIT 许可证。

## 打开软件后会看到什么

主窗口是一张简洁的任务列表。每一行只有任务名和这个任务的总累计学习时长。你可以新建任务，点击已有任务开始计时，也可以不选任务直接开始学习。另有“全屏时钟”和“个人主页”入口。统计日历不会直接占据主窗口。

Windows 上，开始计时会打开独立的计时窗口，任务列表留在原窗口。计时窗口默认全屏，也能缩成可移动的小窗。Android 上会进入沉浸式计时页。

全屏页面参考你喜欢的 A 图：黑底白字或白底黑字，中央是大数字，周围尽量留白。日期写成 `2026 / 09 / 27`，星期写成 `Sun` 等英文缩写，减少中文。深浅模式和数字字体样式可以在个人主页切换。

## 三种显示或计时方式

1. **全屏时钟**：显示当前时间。角落可以手动切换时区。它只是看时间，不记录学习时长。
2. **正计时学习**：从 0 开始累计实际学习时间。可以先不选任务，结束后再从历史记录里把这段时间归到某个任务。
3. **番茄钟**：按设置中保存的默认专注时长倒计时。专注结束自动进入休息。休息结束后停下来等待你点击开始下一轮，防止你离开时一直自动记时。休息可以提前结束，随后选择下一轮或结束。第一版没有长休息。

正计时和番茄钟都能暂停、继续、提前结束；结束时保存真正学习的时长。暂停和休息不算学习。阶段结束只在应用内提示，不播放声音，也不发系统通知。

如果应用意外关闭或设备休眠，进行中的专注计时会按实际经过的时间继续累计，重新打开后恢复显示。番茄钟的休息如果早已结束，则恢复到“等待开始下一轮”，不会自动把无人使用的时间算作学习。

## 任务、历史记录与个人主页

个人主页有每天、每周、每月的累计时长、日历和历史记录。电脑把鼠标移到某天、手机点击某天时，会看到那天学了多久；点进去可以看具体记录。一周从周一开始。跨越午夜的学习记录，会按实际发生的时段分到两天。

历史记录可以修改任务归属、修改计入的时长，或删除。修改后统计会更新。同一账号下任务名不能重复。任务可以改名；删除任务时，以前的计时记录仍保留为“未归类”，以后可以重新分配。

个人主页还能设置统计使用的时区；初始为上海时区。全屏时钟临时查看其他时区，不会改变日历如何统计。

## 登录、断网与多设备

第一版用邮箱和密码登录，数据保存在腾讯云 CloudBase。登录后，同一账号在电脑和手机上看到同一份任务、记录与正在进行的计时；同一时间只允许一个计时器运行。其他登录方式以后可以增加。

断网时，已登录过的设备仍可计时并保存记录，联网后自动同步。如果两台设备在都断网时各自开始了重叠的计时，联网后会让你选择哪段有效，不会悄悄把两段都算进去。同步失败时，本机保留记录并稍后重试。

## 发布前怎样检查

会检查暂停与继续、提前结束、番茄钟循环、关闭后恢复、跨日统计、历史修改与删除、断网保存、重新联网同步，以及两台设备意外同时计时的处理。第一版 GitHub 发布页会提供 Windows 和 Android 下载文件、安装说明及源代码。账户、签名和云服务的私密信息不会放进公开仓库。
