# Timefold V0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 用户已要求由主代理连续完成并测试复核；执行方式沿用 Native。

**Goal:** 在独立 V0.3 中交付可切换中英文、采用深灰浅灰配色与透明原始 A1 图标的 Timefold，并提供本机预览。

**Architecture:** 采用集中翻译资源与 Flutter 本地化委托；语言偏好沿用已有设置存储。界面在展示时读取语言，Windows 子窗口通过既有外观通知接收语言变化，不重建计时器。名称、图标和主题只影响展示，保持数据库、应用包标识与安装器身份兼容。

**Tech Stack:** Flutter/Dart、Flutter SDK 本地化与 ARB、现有 Drift 设置存储、desktop_multi_window、GitHub Actions；SVG 为图标源文件。

**Spec:** `docs/superpowers/specs/2026-09-28-timefold-v0.3-design.md`

## Global Constraints

- 只在 `D:/Timer/versions/V0.3` 对应的独立工作目录修改；保留已归档版本。
- 名称 **Timefold**；对外版本 V0.3，内部版本 `0.3.0+3`。
- 图标使用第一轮原始 A1；透明背景，不添加底板或装饰边框。
- 灰底 `#141414`，主文字 `#C4C4C4`，辅助文字 `#A8A8A8`；其他主题与 V0.2 字号保留。
- 中文和 English 即时切换并持久化；首次按系统语言选择，非中文系统使用英文。
- 保留任务原名、数据库位置、包标识、计时状态；全屏日期及英文星期缩写保留。
- 不新增 CloudBase 环境、公共 Android 签名或 iOS 上架流程。

## Review Focus

- 已有安装无语言偏好或偏好值损坏：可正常载入，按系统语言回退；见任务 1。
- 有运行中的计时器或 Windows 子窗口：切换语言不重置时间和暂停状态；见任务 2。
- 已显示的错误或离线消息：切换语言后重新翻译，不保留旧语言的缓存字符串；见任务 2。
- 英文按钮较长、手机窄屏及紧凑窗口：导航、弹窗、计时控制不溢出；见任务 2。
- 旧记录及安装器升级身份：改名不建立新的数据库或安装身份；见任务 4。

## 文件职责

- `lib/l10n/app_language.dart`：语言解析与系统回退。
- `lib/l10n/app_zh.arb`、`app_en.arb`、`l10n.yaml`：全部应用翻译与生成配置；生成类为 `AppLocalizations`。
- `lib/l10n/app_notice.dart`：结构化应用提示及其本地化映射。
- `lib/app.dart`、`app_host.dart`、`main.dart`：语言状态、根应用委托及 Windows 通知。
- `lib/features/**`：各已有页面使用翻译资源；不另建页面体系。
- `lib/ui/app_appearance.dart`：灰色主题色值。
- `assets/branding/`、平台图标与显示名称、安装脚本：Timefold 身份资源。
- 新增 V0.3 发布工作流与发行说明；旧发布工作流保留。

## Task 1: 语言资源与偏好

**Files:** `pubspec.yaml`、`l10n.yaml`、`lib/l10n/app_language.dart`、`lib/l10n/app_zh.arb`、`lib/l10n/app_en.arb`、生成的 `lib/l10n/generated/app_localizations*.dart`、`lib/app.dart`；测试 `test/data/language_settings_test.dart`。

**Interfaces:** `enum AppLanguage { zh, en }`；`Locale get locale`；`AppLanguage resolveLanguage(String? saved, Locale systemLocale)`；`AppServices.language`；`Future<void> AppServices.setLanguage(AppLanguage value)`。生成的 `AppLocalizations.of(context)` 提供页面文案。`AppServices.fake` 默认中文，保持已有中文测试确定性，可传入英文。

- [ ] 写失败测试：`resolveLanguage(null, Locale('zh','TW')) == AppLanguage.zh`；`resolveLanguage('bad', Locale('fr')) == AppLanguage.en`；保存英文并重新创建服务后 `language == AppLanguage.en`，任务名称仍为“数学”。
- [ ] 在独立目录准备依赖后运行 `flutter test test/data/language_settings_test.dart --no-pub`，确认新增行为尚未实现而失败。安装依赖时记录本机已知的 Windows 符号链接限制，不把它误报为测试通过。
- [ ] 添加 SDK 本地化依赖与 ARB 生成配置；实现上述语言接口；语言存入已有设置键 `language`，不迁移数据库。
- [ ] 在主应用和子窗口的 `MaterialApp` 设置 locale、supportedLocales 与 localizationsDelegates；生成翻译资源。
- [ ] 运行该测试，预期全部通过；提交语言基础及测试。

## Task 2: 全界面翻译与子窗口即时更新

**Files:** `lib/features/launcher/*.dart`、`lib/features/profile/*.dart`、`lib/features/auth/auth_page.dart`、`lib/features/timer/*.dart`、`lib/app.dart`、`lib/app_host.dart`、`lib/main.dart`、`lib/platform/timer_window.dart`、`lib/l10n/app_notice.dart`、两份 ARB；测试 `test/features/language_switch_test.dart`、`test/features/appearance_refresh_test.dart`、`test/features/immersive_layout_test.dart` 与现有页面测试。

**Interfaces:** 设置页调用 `services.setLanguage`；页面读 `AppLocalizations.of(context)`。外观通知载荷增加 `language: services.language.name`；`applyAppearance` 增加可选 `AppLanguage? language` 参数，旧调用保持兼容。`AppNotice` 存语义代码及可选数量参数，`String resolveNotice(AppLocalizations strings, AppNotice notice)` 在展示时翻译；已有同步与账号提示改用此方式，不缓存已翻译字符串。

- [ ] 写失败测试：设置点 English 后任务主页与四个分区标题为英文，自定义任务名“数学”不变；已有离线提示随语言更新；重复应用相同偏好不重复通知。
- [ ] 写失败测试：运行中及暂停计时接受英文外观更新后，计时阶段、开始时间与累计时长均不变；英文界面在 360×640 手机、560×320 紧凑窗口不产生布局异常。
- [ ] 运行新增测试，确认因未翻译或未接收语言而失败。
- [ ] 将全部可见文案集中到 ARB，包括空列表、确认框、错误、账号状态、编辑验证、辅助提示与控件可访问标签。未知外部错误使用通用本地化提示，不直接暴露错误对象。
- [ ] 扩展现有主窗口监听、窗口复用与 appearance handler；子窗口只更新偏好，不通过重新 load 计时器实现语言切换。保留全屏日期、星期与任务名。
- [ ] 更新已有测试的预期并运行全部页面测试，预期通过；提交完整翻译与窗口同步。
