# Timefold V0.3 · 中英文与品牌试用版

## 本版改进

- 软件名称改为 **Timefold**。
- 使用第一轮原始 A1 图形作为图标，保持原始形状和粗细，源图及平台图标资源采用透明背景。
- 在 **个人主页 → 设置 → 语言 / Language** 切换中文和 English，立即生效并保存；首次按系统语言选择。
- 菜单、任务、历史、统计、账号与提示文案支持两种语言；自定义任务名保留原文。
- Windows 主窗口和已打开的计时/时钟窗口同步语言偏好，切换不重置计时状态。
- 灰色主题改为背景 `#141414`、主文字 `#C4C4C4`、辅助文字 `#A8A8A8`；白底黑字与黑底白字主题仍可选择。
- 英文日历月份标题适配窄屏；设置内容可滚动，手机继续使用导航抽屉。

## 下载与本机预览

Windows 发行附件包含 `Timefold-0.3.0-preview-windows-setup.exe` 与 `Timefold-0.3.0-preview-windows-portable.zip`。

便携版解压后双击 `study_timer.exe`。保留整个解压目录，程序所需 DLL 和数据资源不能拆开。使用前关闭旧版 Timer/Timefold。

用户本机将准备 `D:/Timer/previews/V0.3` 和打开快捷方式，无需再次下载或安装。源代码与完整交付归档单独保存在 V0.3 目录。

## 记录兼容与版本保留

沿用原有 Android 包标识、Windows 可执行文件、安装器 AppId 和本机数据库位置。改名不会主动清除学习记录。新版本在独立目录开发，V0.1、V0.2 的源码与发行附件保留。

应用内部版本为 `0.3.0+3`。透明黑色图标的桌面显示会受到系统背景和启动器呈现方式影响；应用提供的资源不含人为底板。

## 验证与可用范围

发行流程只在同一源码提交的 Check 测试、Windows 构建/设备流程和 Android 构建/设备流程成功后发布其 Windows 构建产物。具体结果记录在本机交付验证报告中。

CloudBase 环境尚未配置，当前公开 Windows 试用版提供本机记录；邮箱账号和跨设备同步仍需真实环境部署及权限验收。Android 公共安装包仍需长期签名密钥；本版不发布临时 CI 密钥签名的 APK。iPhone 版尚未发布。

Windows 原生第二窗口即时语言同步需要实际桌面操作复核。组件状态测试验证更新不重置计时，但不替代原生 IPC 的人工检查。
