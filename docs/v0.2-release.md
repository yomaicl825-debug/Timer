# Timer V0.2 · 界面改进试用版

本版在独立的 V0.2 工作目录开发；V0.1 源码标签、发行文件和本机归档保持原样。

## 改进

- 中文界面使用完整的中文字体及统一常规字重，页面标题单独加粗；修正同一个词内文字粗细不一致的问题。
- 普通界面字号整体放大约 25%：正文和按钮约 18–20，标题约 24–28。
- 个人主页改为左侧导航、右侧内容：日历统计、任务管理、历史记录、设置。
- 桌面侧栏默认展开，可收起；手机通过左上角菜单选择页面，选择后关闭菜单。
- 默认进入日历统计，显示今日、本周、本月累计时长；主任务页保留简洁布局。
- 三种外观：白底黑字、黑底白字、深灰底白字。主窗口和独立计时窗口使用相同主题。
- 时钟及计时数字随窗口放大，在小窗口中自动缩小，避开角落和底部按钮。
- 保留现有本机记录、深浅主题与数字字体设置；新增灰色主题可保存并在重启后恢复。

## 下载

下载 `Timer-0.2.0-preview-windows-setup.exe` 安装，或完整解压 `Timer-0.2.0-preview-windows-portable.zip` 后运行 `study_timer.exe`。校验值在 `SHA256SUMS.txt` 中；安装包暂无商业代码签名。

源码和 Windows 安装包是独立的新版本。更新安装会继续使用现有本机数据库；本机 V0.1 源码与下载归档不会被改写。

## 测试与限制

发行工作流要求格式检查、静态分析、Flutter 回归测试、Windows 构建与设备流程、Android 构建与模拟器流程通过后才发布 Windows 包。

CloudBase 真实环境尚未配置，邮箱登录和跨设备同步仍不可用。Android 公开 APK 待配置长期签名密钥，iPhone 版尚未发布。计时数据仍仅保存在本机，尚无数据导出恢复入口。

CloudBase 与 Android 配置步骤见源码中的 `docs/cloudbase-setup.md`、`.github/workflows/release.yml` 和 `docs/v0.1-release.md`。

后续版本默认递增小数点后的序号，增加主版本号须由用户确认。
