# Timefold V0.4 · 云端与 Android 试用版

## 本版范围

- 以已发布的 V0.3 界面和计时功能为基础，内部版本号更新为 `0.4.0+4`。
- Windows 与 Android 构建连接已配置的腾讯云 CloudBase 环境；用户可用邮箱密码注册或登录，数据按账号保存和同步。离线时仍可在本机计时，恢复联网后再同步。
- 首次提供使用长期固定密钥签名的公开 Android APK。后续 Android 更新沿用同一包标识和签名证书。
- 发行包由同一源码提交的自动化检查、Windows 桌面流程和 Android 模拟器流程通过后生成；发布时另外核对 APK 的签名证书指纹。

## 安装

Windows 可使用安装包或便携版。便携版需完整解压后运行 `study_timer.exe`。Android 下载 APK 后按系统提示安装；如设备阻止安装，需为当前下载来源开启安装权限。

已有本机记录继续保留。登录后会按当前账号同步数据，使用不同账号时只显示各自记录。首次使用建议先记录一段短时间，再到个人主页核对历史记录。

## 已知边界

- iPhone 版仍未发布。
- 云端服务依赖 CloudBase 环境的可用性和免费体验套餐；实际用户注册、双设备同步和账号隔离需在公开发布前完成验收。
- GitHub 安装包不经过应用商店审核。Android 实机安装与更新覆盖也需在公开发布前复核。

## 版本保留

V0.1、V0.2、V0.3 的源码与发行附件保留。V0.4 在独立工作区开发；发行包只包含 V0.4 的构建产物，不改动旧版本。
