# 隐私与数据

Timer 记录任务名、学习时间段、账号邮箱与偏好设置。未配置云服务或未登录时，记录只存储在设备的应用数据库中。使用账号时，客户端把该账号的记录提交到腾讯云开发 CloudBase；数据库规则和云函数按账号 UID 限制访问。

计时页面无广告、分析 SDK 或社交展示。项目不主动收集通讯录、定位和其他应用活动。邮箱密码由 CloudBase 身份服务处理，应用不在自己的数据库存储明文密码。

账号登录与云端权限检查需要部署者自己的 CloudBase 环境。云端上线前必须进行两账号隔离与并发计时验收。离线冲突处理和数据导出仍需在真实环境完整验证；在此之前不要把本应用当作唯一备份。

如要删除本机数据，可通过系统卸载并清除应用数据。云端账号数据删除流程会在云环境上线时提供。
